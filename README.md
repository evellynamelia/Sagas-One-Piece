# ☠️ One Piece — As Sagas

Um site dedicado às principais sagas de **One Piece**, criado para apresentar de forma simples e visual diferentes momentos da jornada de Monkey D. Luffy e sua tripulação.

## ✦ Sobre o projeto

Este projeto foi desenvolvido como uma prática de **desenvolvimento web**, utilizando principalmente **HTML e CSS**.

A proposta é reunir as principais sagas de One Piece em uma única página, apresentando:

- 📖 Informações sobre cada saga
- 🖼️ Imagens relacionadas
- 🎬 Trailers em vídeo
- 🧭 Navegação entre as sagas
- 📱 Layout organizado e responsivo

O objetivo foi praticar a criação de páginas estruturadas, estilização com CSS e organização de conteúdo.

---

## 🎨 Design

O visual do site foi inspirado no universo de **One Piece**, utilizando:

- Fundo escuro
- Detalhes em vermelho
- Tipografia simples e legível
- Elementos inspirados no universo pirata
- Seções individuais para cada saga

A página inicial apresenta uma introdução sobre a história de One Piece e, em seguida, as sagas são organizadas em diferentes seções.

## 📚 Sagas apresentadas

O site apresenta diferentes momentos da história de One Piece, incluindo:

- East Blue
- Alabasta
- Skypiea
- Water Seven
- Thriller Bark
- Guerra de Marineford
- Homens-Peixe
- Dressrosa
- Wano
- Egghead

Cada seção possui informações específicas sobre a respectiva saga e elementos visuais para complementar a apresentação.

---

## 🎬 Trailers

Algumas seções também contam com vídeos relacionados às sagas, incorporados através do **YouTube**.
